# Arpitha M portfolio

## Run on your computer

1. Install Node.js (LTS version) from nodejs.org.
2. Open this folder in a terminal.
3. Run `npm install` once.
4. Run `npm run dev` and open the address it prints.

## Where to edit text

All wording lives in `src/content/`. Placeholders appear in [square brackets].

## Checks

- `npm run lint` finds code mistakes.
- `npm run build` makes the final site in `dist/`.
